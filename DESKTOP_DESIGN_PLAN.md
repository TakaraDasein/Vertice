# Plan de Mejoras de Diseño Desktop (VÉRTICE)

Este documento describe las mejoras visuales y de experiencia de usuario (UX) planificadas para la versión de escritorio del sitio web de VÉRTICE.

**Objetivo:** Elevar la percepción de calidad ("premium feel"), mejorar la legibilidad y asegurar una navegación fluida y atractiva en pantallas grandes.

---

## 1. Hero Section (`HeroHome`)
- [x] **Tipografía de Impacto:** Aumentar el tamaño del título "Vértice" y mejorar el contraste.
- [x] **Botones Premium:** Aplicar estilos "Glassmorphism" a los botones (transparencia + desenfoque + borde sutil).
- [x] **Entrada Escalonada:** Implementar animaciones de entrada secuencial (staggered) para texto y botones.
- [x] **Profundidad:** Ajustar las capas de fondo para que no "aplasten" la profundidad visual.

## 2. ¿Qué es Vértice? (`QueEsVerticeSection`)
- [x] **Glassmorphism:** Refinar el estilo de la tarjeta principal con un efecto de cristal más pronunciado.
- [x] **Transiciones Suaves:** Usar `AnimatePresence` para una transición fluida entre "Qué es" y "Historia".
- [x] **Balance Visual:** Añadir elementos decorativos sutiles (formas abstractas) para equilibrar el espacio negativo.

## 3. Nosotros (`NosotrosSection`)
- [x] **Tarjeta de Perfil:** Añadir un efecto de "glow" (resplandor) suave al pasar el mouse sobre la tarjeta.
- [x] **Badges de Expertise:** Mejorar el diseño de las etiquetas de habilidades (pill shape, colores refinados).
- [x] **Integración de Imagen:** Asegurar que la foto de perfil se integre orgánicamente con el fondo.

## 4. Triple Impacto (`TripleImpactSection`)
- [x] **Efecto Orbital:** Intensificar el brillo y la estela de los orbes al rotar o ser seleccionados.
- [x] **Info Interactiva:** Suavizar la aparición de la información de cada impacto (fade/slide).
- [x] **Legibilidad:** Ajustar tamaños de fuente y contrastes en la tarjeta de información.

## 5. Servicios (`ServicesSection`)
- [x] **Legibilidad de Texto:** Añadir superposiciones de degradado (gradient overlays) en las tarjetas para garantizar que el texto sea legible sobre cualquier imagen.
- [x] **Micro-interacciones:** Refinar las animaciones al pasar el mouse (zoom sutil, elevación).
- [x] **Layout:** Optimizar la distribución del grid y el texto descriptivo.

## 6. Laboratorios (`LaboratoriosSection`)
- [x] **Efecto Tilt:** Implementar un efecto de inclinación 3D sutil en las tarjetas al pasar el mouse.
- [x] **Convergencia Visual:** Rediseñar el elemento visual que conecta los laboratorios para que sea más elegante.

## 7. Footer (`Footer`)
- [x] **Patrón de Fondo:** Añadir un patrón SVG sutil y sofisticado al fondo.
- [x] **Estilos de Formulario:** Aplicar estilos "premium" a los inputs (bordes translúcidos, focus states elegantes).
- [x] **Hover States:** Mejorar la retroalimentación visual en enlaces y botones.
